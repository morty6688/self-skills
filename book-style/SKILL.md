# 书籍章节排版

在保留书籍内容和结构的前提下，统一 Markdown 章节格式。用户指定的格式、术语表和目标渲染器要求优先于以下默认约定。

## 工作方式

1. 阅读待处理章节，识别语言、章节编号、已有锚点、图片路径和图表编号。处理整本书时沿用一致的术语与编号约定；只处理单章时，不假定已经读取其他章节。
2. 按下列规则修改。需要编写标题、图表、注释、公式链接或嵌套列表时，读取 [格式示例](references/format-examples.md) 中对应部分。
3. 对照修改前后的内容核查遗漏、误删、编号与链接。若有可用的目标渲染器，检查公式、HTML 表格和列表的实际显示；未渲染时说明仅完成源码检查。

只请求排版时，不主动翻译全文、改写论述或重编章节。保留数据、数学含义、代码行为、引用来源和资源路径；发现疑似内容错误时单独指出，不凭猜测改正。

## 章节拆分与目录

- 新建或拆分整本书时，在书籍文件夹根目录放置 `menu.md` 作为阅读入口，同级按 `C00.md`、`C01.md`、`C02.md` 等方式保存章节，使用大写 `C`，数字至少补齐两位。
- `C00.md` 通常收录前言、序、译者序等正文之前的内容，保留各部分标题和原有顺序；正文第一章从 `C01.md` 开始，后续文件对应原书章节编号。
- 按章拆分，不将节、小节或单个图表另拆为章节文件。章节所属的图表、表注、章末注释和习题随该章保留，保持内容完整。
- `menu.md` 按阅读顺序列出各文件的相对链接与实际标题，先列 `C00.md` 中的前置内容，再列正文各章。这里的顺序指目录阅读顺序，不依赖文件管理器的排序。
- 拆分或重命名后同步更新目录、跨章节引用、返回链接及受影响的图片相对路径；保留原有锚点，避免丢失内容或覆盖已有章节。仅整理单章时，不自动重组整本书的文件。

目录示例：

```markdown
# 目录

- [前言与序](C00.md)
- [第一章 章节标题](C01.md)
- [第二章 章节标题](C02.md)
```

## 术语与引文

- 中文正文中的人名、地名、书刊名、机构名及专业术语首次出现时，采用“中文名（英文名）”。书刊中文名使用书名号，如《书名》（English Title）。已有术语表或前文章节约定时沿用；否则以本次处理范围为首次出现的判断范围。
- 注释中的作者、书刊及文献名称同样处理。后续出现可使用中文简称；约定俗成且更便于理解的英文术语或缩写可保留英文。纯英文正文不套用中文在前的规则。
- 原文未给出英文名称且无法可靠确认时，保留已知名称，不杜撰对应译名。
- 已有名言或题辞使用 Markdown 引用块，原文可用斜体，中文译文另起一段，署名放在末尾。保留已有出处；不擅自添加名言、作者生卒年或未经核实的来源。

## 图表

- 图片与图题相邻，表格与表题、表注相邻，中间不插入无关正文。保留完整表格及子图顺序，不随意拆表、删行列或修改内容。
- 中文标签统一为“图 1.1”“表 5.1”，编号标签加粗，说明文字用斜体。多子图中的“左：”“中：”“右：”等位置标签用正体，其后说明用斜体。英文正文保留 Figure / Table 等标签。
- 去掉编号后多余的分隔句号，例如 `Figure 1.1. Caption` 在中文译稿中写成 `图 1.1 说明`；保留编号内部的小数点和说明文字中正常的标点。
- 图表标题与正文引用通过 `span` 锚点建立双向链接，规则见“图表、注释与公式的双向链接”。没有正文引用时只保留目标锚点，不生成空的返回链接。
- HTML 表格保留必要的 `rowspan`、`colspan`、对齐及其他属性。`<table>` 前和 `</table>` 后各留空行；只删除表格外围确属多余或错误嵌套的 `<p>` 标签，不全局删除段落标签。
- 表注保留原有 `*`、`†`、`‡`、`§`、`¶` 等标记，引用采用上标，注释放在表后并提供返回链接。HTML 表格内部使用 HTML 链接，不依赖 Markdown 在 HTML 块中解析。

## 章节与小节标题的单向链接

- 正文明确提及某章、某节或某个标题对应的内容时，可将对应文字直接链接到该标题；只有目标明确时才添加，不将普通术语的每次出现都改成链接。
- 标题引用采用单向链接：同文件使用 `[第 2.1 节](#c02-sec-2.1)`，跨文件使用 `[第 2.1 节](C02.md#c02-sec-2.1)`。引用处无需 `R_` 锚点，目标标题不添加返回链接；多处引用可指向同一个标题锚点。
- 优先复用已有且唯一的标题锚点。需要新增时，在标题文字外包裹 `span`，如 `## <span id="c02-sec-2.1">2.1 基本概念</span>`；章标题可使用 `c02-chapter`，无编号标题可使用 `c00-preface` 等稳定且含义明确的 ID。保留原有标题文字和层级，同名标题使用不同 ID。
- 若目标环境过滤 HTML，使用经确认的渲染器自动标题锚点或其支持的显式锚点语法，不猜测中文、标点或重复标题的自动锚点。标题修改或章节移动后，检查所有指向它的链接。
- `menu.md` 需要定位到章内具体标题时，也使用上述单向链接。图题、表题及公式标签仍采用下节的双向链接规则。

## 图表、注释与公式的双向链接

- 优先保留已有且唯一的锚点。新增时采用 `c01-fig-0001`、`c05-tbl-0001`、`c02-note-0001`、`c02-formula-2.1` 等形式；章节前缀按实际章节调整，附录可用 `app-a`。锚点名不改变书中显示的编号。
- 目标使用 `id="目标ID"`，首处引用使用 `id="R_目标ID"`。同一目标再次被引用时，使用 `R_目标ID-2`、`R_目标ID-3` 等唯一锚点，不能复制相同的 `id`。
- 引用指向目标；图表标题或公式标签返回首处引用，存在多处引用时追加“返回 2”等链接。注释末尾为各引用提供返回链接。
- 跨文件引用使用正确的相对文件路径和片段，例如 `C02.md#c02-formula-2.1`；返回链接也必须包含相应路径。不要将跨文件目标误写为当前文件内的锚点。
- 若目标环境过滤 HTML 或不支持这些锚点，使用该环境支持的链接方式并说明限制，不宣称无法生效的双向链接已完成。

## 注释与公式

- 普通注释通常集中在章末“注释”节，正文引用使用上标，注释末尾添加返回链接。沿用已有脚注编号，不将表注强制移到章末。
- 行内公式使用 `$X_{1}$` 等标准 LaTeX 写法；仅规范不改变数学含义的空格和排版，不改变量、运算符或公式内容。
- 独立公式使用单独成行的 `$$` 包围，并与周围段落留空行。已有编号的公式保留 `\tag{2.1}`，公式前放置带锚点的“公式 2.1”标签，正文引用显示为 `(2.1)`，并建立双向链接。
- 无编号公式不强制编号。目标渲染器不支持 `\tag` 时，使用独立文本标签保留编号，并说明兼容处理。

## 列表与代码

- 保留习题的题号、子题标识及从属关系。子项和续行缩进到父项正文起始列；嵌套层级逐层增加，使用空格而非制表符。不要用统一替换空格的方式破坏多位数题号或代码块。
- 行内代码使用反引号，如 `np.array()`；独立代码使用围栏代码块，语言已知时标注语言。内容包含反引号围栏时，外层使用更长的围栏。
- 不翻译代码标识符，不改变代码内容，也不对代码块内的文字应用术语替换或数学格式规则。

## 完成检查

- 涉及章节拆分时，检查 `menu.md` 阅读顺序、章节文件名及目录链接与实际文件一致，前置内容与正文均完整保留。
- 对照差异确认正文、图片、表格行列、注释和公式没有遗漏或意外变化。
- 检查锚点唯一、每个片段链接有目标、返回链接能对应引用位置，跨文件路径有效。
- 检查章节、小节标题引用指向正确标题；此类单向链接不要求返回锚点或返回链接。
- 检查图表编号、公式编号和注释标记前后一致，图片路径有效；对当前范围外无法核实的资源明确列出。
- 检查标题层级、列表缩进、代码围栏和 HTML 标签完整，并简要说明修改范围及尚未解决的问题。
