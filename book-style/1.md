# Skill Instructions

1. 术语：遇到人名、地名、书名期刊名、机构名、学术名词或其他专业术语，第一次出现时按照先中文名后英文名的规则。例如杰西・利弗莫尔（Jesse Livermore）、《股票作手回忆录》（Reminiscences of a Stock）、贝莱德（BlackRock）、温特斯方法（Winter's method）、最小二乘法（Least Squares Method）等。包括注释中的作者名、书名、期刊名和文献名也做类似处理。

   - 一些约定俗称，更方便用英文描述的术语或缩写在第二次或之后出现时可以直接用英文原文
   - 英文格式忽略此条

2. 名人名言：要添加引用，例如：

   > _Pluralitas non est ponenda sine necessitate_.
   >
   > 如无必要，勿增实体。
   >
   > ——威廉・奥卡姆（William of Ockham，约 1285–1349）

3. 图/表 基本格式：

   - 不要分割图片和图片说明，不要以任何方式分割或打散表格内容；不要无故删改图/表内容

   - 标题建立span标签双向链接。标题格式如下，形如 图 x.x 或 表 x.x 的字样加粗，其他说明使用斜体。如果包含多张图片，则部分使用斜体，如以下引用所示：

     >在这个应用中（本书始终将其称为工资数据集（Wage data set）），我们考察美国大西洋沿岸中部地区一组男性工资相关的若干因素。具体而言，我们希望理解员工年龄、受教育程度以及日历年份与其工资之间的关系。比如，请看 [<span id="R_c01-fig-0001">图 1.1</span>](#c01-fig-0001) 左图，它展示了数据集中每位个体的工资与年龄的关系。可以看出，工资会随着年龄增长而上升，但在大约 60 岁之后又开始下降。蓝色曲线给出了特定年龄下平均工资的估计值，使这一趋势更加清晰。给定某位员工的年龄，我们可以利用这条曲线预测其工资。不过，从图 1.1 也可以明显看出，这个平均值周围存在相当大的变异性，因此仅凭年龄很难对某个具体男性的工资作出准确预测。
