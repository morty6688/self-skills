# 格式示例

以下示例展示新建链接时的默认格式。实际编辑时替换章节号、编号及路径，并优先兼容文档已有锚点。除明确标注的配套示例外，各代码块彼此独立，不应直接拼接成一个章节。

## 标题的单向链接

目标文件 `C02.md` 中的标题与同文件引用：

```markdown
# <span id="c02-chapter">第二章 基本方法</span>

本章先介绍[基本概念](#c02-sec-2.1)。

## <span id="c02-sec-2.1">2.1 基本概念</span>

本节正文。
```

在其他章节或 `menu.md` 中引用上述标题：

```markdown
- [第二章 基本方法](C02.md#c02-chapter)
- [第 2.1 节 基本概念](C02.md#c02-sec-2.1)
```

这两个代码块配套展示跨文件引用。标题只提供目标锚点，不添加返回链接；多个引用可以共享同一目标。

## 列表中的公式与续段

`1. ` 的正文起始列为第 4 列，因此下面的公式和续段均缩进 3 个空格。公式前后保留空行，但不退回顶格；若图表属于该列表项，也使用相同的内容缩进。

```markdown
1. 拟合线性模型，估计各个系数：

   $$
   Y \approx \beta_0 + \beta_1 X_1.
   $$

   常用的估计方法是最小二乘法。此段仍属于第一项。

2. 用拟合好的模型进行预测。

这里是整个列表之后的独立正文，恢复顶格。
```

如果公式顶格结束了列表，后续正文又以四个空格开头，Typora 可能把它识别为缩进代码块。应恢复整段正确的列表层级，而不是只删除该段缩进或全局替换空格。

## 公式与字母格式检查

以下修复只适用于已确认的提取或排版错误，不作为跨正文和代码的全局替换规则：

| 问题 | 修复示例 | 判断依据 |
| --- | --- | --- |
| 字母标签被拆开 | `\operatorname{P r}` → `\operatorname{Pr}`；`\mathsf{s a l e s}` → `\mathsf{sales}` | 确认是概率算子或变量名称，保留原有字体命令；不要合并真正的变量乘积。 |
| 小数内部出现空格 | `0 . 0 5` → `0.05` | 确认是同一个数；矩阵中的 `0 1`、分开的索引或数字列表不能据此合并。 |
| 数学模式中混入 HTML | `$R<sup>2</sup>$` → `$R^{2}$` | 数学上下标使用 LaTeX；数学模式之外的合法 HTML 上标不受影响。 |
| 不等号写成两个符号 | `$x >= 0$` → `$x \geq 0$` | 仅处理数学模式，代码中的 `>=` 保持原样。 |

诸如 `Loss + Penalty` 两侧的上标星号，既可能是提取错误，也可能具有数学含义；应对照原书后再决定是否删除。不要把某一本书中的修正推广成删除所有星号的规则。

公式提取应保留 `\$` 这样的转义字符，避免把货币符号误作公式结束。解析器可以发现语法错误，但也可能接受会显示成普通字母的 HTML 标签或错误单词。因此批量解析仍需配合针对提取痕迹的检查；未在 Typora 等目标渲染器中查看时，应明确说明。
